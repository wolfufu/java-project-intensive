# Car Sorting Application 

Java-приложение для сортировки данных об автомобилях.

## О проекте

Приложение реализует алгоритм **`сортировки выбором`**  массива состоящего из объектов кастомного класса. Проект соответствует Java code conventions.

## Архитектура

### Основные компоненты

- **`Car`** - кастомный класс с паттерном Builder
- **`Menu`** - главное меню приложения с циклическим выполнением
- **`FileDataLoader`** - загрузка данных из файлов
- **Валидация** - проверка корректности вводимых данных

### Поля класса Car

- `power` (int) - мощность автомобиля в л.с.
- `model` (String) - модель автомобиля
- `year` (int) - год выпуска
